## 2026-08-12

**Words:** viewport, payload, marquee, skeleton, parallax

* **ParallaxHero** - Full-viewport hero with scroll-linked parallax layers for eyebrow, headline, subtitle, and CTA — adds depth and motion without scroll-jacking the page.
* **MarqueeRibbon** - Infinite horizontal marquee duplicating its track for seamless looping text, with configurable speed, direction, and optional pause-on-hover for readable highlights.
* **SkeletonReveal** - Loading wrapper that mirrors final layout geometry with shimmer skeleton placeholders, then crossfades into real content so nothing jumps when data arrives.
* **ViewportSnapDeck** - Native CSS scroll-snap deck where each slide fills the viewport for vertical storytelling, with dot navigation tracking the active slide via IntersectionObserver.
* **PayloadPanel** - Dev-tool panel showing API endpoint, streaming status, labeled fields, and an expandable raw JSON drawer — declined as too domain-specific for a generic component library.
