# TerminusLedgerFloor

## Creative direction

**Style:** Luxury
**Typography:** Ruled ledger lines, stamp serif brand, marginalia links
**Layout:** Footer as end-of-book ledger page — horizontal rules, brand embossed center, links as margin notes
**Color:** Parchment `#f7f2e8`, ink `#1c1916`, stamp crimson `#8b2942`, rule gold `#c9a962`
**Motion:** subtle fade-in on rules; micro underline on link hover
**Signature:** Ruled ledger lines with brand as wax-stamp medallion at terminus

## Role

- footer

## Look

- Full-viewport ledger terminus — gold rules stack like accounting paper; brand sits in a crimson stamp medallion; navigation links appear as marginalia between rules.
- Not a four-column sitemap — the page ends on paper.

## Motion

- Role: chrome
- Moves: fade-in, micro
- prefers-reduced-motion: static rules and stamp

## Page behavior

- Root: `min-h-[100svh] w-full`
- Footer owns viewport as closing sheet

## Neighbors

- Above: any section — ledger visually closes the scroll

## Width model

- Full browser width

## Image ratios

- Optional stamp mark: 1/1 if logo image provided

## Headlines

- Brand as large stamp text in medallion

## Responsive

- Mobile: fewer rules, smaller stamp, links stack
- Desktop: wide ruled field, links in right margin column

## 3D

- None
