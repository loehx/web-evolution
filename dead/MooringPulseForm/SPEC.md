# MooringPulseForm

## Creative direction

**Style:** Futuristic
**Typography:** Mono labels, wide tracking on field indices
**Layout:** Mooring bollards along left rail; form fields tethered via cable lines that pulse when focused
**Color:** Deep harbor `#0a1628`, buoy amber `#ffb347`, cable cyan `#4ecdc4`, fog `#c8d6e5`
**Motion:** pulse on focus/valid fields; stagger on mount; micro on submit
**Signature:** Vertical bollard rail with glowing pulse rings that climb as fields complete

## Role

- contact form

## Look

- Full-viewport harbor night — mooring posts line the left edge; each field connects with a cyan cable; amber pulses climb the bollards when inputs are valid.
- Domain-agnostic inquiry ritual, not a JSON inspector or floating card.

## Motion

- Role: primary interaction
- Moves: pulse (custom), stagger, fade-in
- prefers-reduced-motion: static glow states without animation

## Page behavior

- Root: `min-h-[100svh] w-full`
- Form owns the stage

## Neighbors

- Above: editorial or hero
- Below: footer — cables visually moor to next section

## Width model

- Full browser width

## Image ratios

- None

## Headlines

- HTML title + optional eyebrow

## Responsive

- Mobile: bollards shrink, fields full width
- Desktop: wide cable spans to fields on right two-thirds

## 3D

- None
