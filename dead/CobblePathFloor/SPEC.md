# CobblePathFloor

## Creative direction

**Style:** Playful
**Typography:** Rounded sans for brand; small caps on cobble link labels
**Layout:** A winding cobblestone path across the footer stage; navigation links sit on individual stones
**Color:** Cobble gray `#8b8680` + moss green `#5a7247` + warm cream `#f5f0e8`
**Motion:** Stagger fade-up on stones; gentle bounce on hover (desktop)
**Signature:** Stepping-stone navigation path that winds from bottom-left to brand crest at center-top

## Role

- footer

## Look

Not a link list. A village lane you walk. Brand sits at the path origin; links are stones you step on.

## Motion

- Role: chrome
- Moves: stagger fade-up, micro bounce on hover
- Durations: `motionDuration.standard` for stagger
- prefers-reduced-motion: static path layout

## Page behavior

- Root: `min-h-[100svh] w-full`
- Closing stage of the page

## Neighbors

- Below: none (page end)

## Responsive (mobile → tablet → desktop → large)

- Mobile: fewer stones, stacked path, no hover bounce
- Tablet: winding path with 4-6 stones
- Desktop / large: full serpentine path with hover bounce on stones
- Touch-first; legal along the path edge
