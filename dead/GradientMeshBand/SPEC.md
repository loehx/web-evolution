# GradientMeshBand

## Look
- Soft animated violet/fuchsia/cyan mesh blobs behind semi-transparent dark veil
- Eyebrow, headline, body, optional pill CTA — left or center aligned

## Page behavior
- Section-level band; sits between page blocks
- Background motion is decorative only (aria-hidden blobs)

## Neighbors
- Above: hero, nav, or feature grid
- Below: testimonials, footer, or card rows

## Viewport and resize
- Mobile: reduced padding, smaller headline
- Desktop: wider padding, larger type
- prefers-reduced-motion: mesh blobs should freeze (handled via Motion)
