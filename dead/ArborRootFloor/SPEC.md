# ArborRootFloor

## Creative direction

**Style:** Playful
**Typography:** Rounded serif brand, small-caps links
**Layout:** Tree roots spread across the viewport floor with brand in the trunk
**Color:** Forest floor (#2d4a3e) + bark brown (#5c4033) + moss green (#7cb342)
**Motion:** Roots grow in on load; links pulse on hover
**Signature:** Playful footer as a spreading root system — brand sits in the trunk, links on root branches

## Role

- footer

## Look

- Full-viewport forest floor footer: SVG root branches spread from a central trunk medallion; navigation links sit on root tips; legal type along the soil line.

## Motion

- Role: chrome
- Moves: fade-in, stagger
- Durations: emphasis for root draw, micro for link hover
- prefers-reduced-motion: static roots

## Page behavior

- Root: `min-h-[100svh] w-full`
- Scroll: terminal slice

## Neighbors

- Above: contact form or content
- Below: none

## Width model

- Full browser width

## Image ratios

- N/A (SVG roots)

## Headlines

- Brand: HTML in trunk medallion
- Links: small-caps anchors

## Responsive (mobile → tablet → desktop → large)

- Mobile: fewer root branches, stacked links below trunk
- Tablet: more branches visible
- Desktop: full root spread with orbital links
- Large: roots extend to viewport edges
