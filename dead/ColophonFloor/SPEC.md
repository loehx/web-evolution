# ColophonFloor

## Creative direction

**Style:** Playful
**Typography:** Site name as a floor — oversized, almost unreadable close-up
**Layout:** The footer is a room: huge brand underfoot, links as stepping stones
**Color:** Coral `#ff4d3a` + ink black
**Motion:** Chrome / restrained — almost static
**Signature:** End-matter as architecture, not a 4-column link dump

## Look

Full viewport. Legal line as a horizon. Links are few and huge.

## Motion

- Role: chrome
- Moves: none required; optional fade-in
- prefers-reduced-motion: static

## Page behavior

- Root: `min-h-[100svh] w-full`
- Last stage on the page

## Neighbors

- Above: InquiryChamber
- Below: none (document end)

## Responsive (mobile → tablet → desktop → large)

- Mobile: stacked link list, brand still huge but wrapping
- Tablet: two-column links
- Desktop / large: brand bleeds to the edges; links in a single row of stones
