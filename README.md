# web-evolution

Bold, generic web components evolved through review. Staging → preview → keep or die.

## Structure

- `staging/` — components awaiting review
- `alive/` — kept components
- `dead/` — declined components
- `MEMORY.md` — lessons from declined reviews

## Dev

```bash
npm install
npm run dev
```

- Demo: http://localhost:5173/
- Previews: http://localhost:5173/preview

## Workflow

Use the `/evolve` Cursor skill to run the full invent → preview → review loop.
